## Context (read before starting)

- Contract to keep exactly as it was reviewed: `docs/superpowers/specs/2026-11-23-t-017-add-a-measurable-9-16-reframing-design.md` on `office/T-017-r2` (AC2-AC19 and its Decisions). In short: `reframe.crop_width(w, h, aspect=9/16) = min(w, max(2, 2*floor(h*aspect/2)))`, so the crop is even and full height. `reframe.sample_times(d)` is the 5 Hz grid over [0, d). `reframe.plan_crop(video, aspect=9/16)` returns `[(t, width/2) for t in sample_times(duration)]`, a static centre that decodes no frames. `media.probe_size(path) -> (width, height)`. `eval_crop.evaluate_dir(dir)` interpolates plans with `np.interp` and reports `{ball_in_crop, players_in_crop, jitter, seconds_per_min, per_clip}`. The `sportscut eval-crop DIRECTORY [--json]` CLI uses exit 2 and `sportscut eval-crop: error: <msg>`.
- Why T-017 never merged: its branch point was `592f6a8`. Since then main gained T-011, T-012, T-016 and T-023, and those touch `sportscut/cli.py`, `tests/test_cli.py`, `README.md`, `DECISIONS.md` and `INDEX.md`. **`git checkout office/T-017-r2 -- <file>` on those shared files would delete T-012/T-023/T-016 code** (`git diff --stat main office/T-017-r2` shows -2800 lines). Only new files and files whose `main..office/T-017-r2` diff has 0 deletions may be checked out whole.
- Root cause of the T-017 block in `tests/test_t023_acceptance.py::test_ac16_protected_implementation_files_are_unchanged_from_main` (lines 517-537): it runs `git diff --name-only main -- <protected>`. That compares the worktree with the *current* tip of `main`, so a branch fails as soon as main changes a protected file after the branch point, even though the branch never touched it. The fix uses the merge base, which is the same reasoning as the T-011 review decision (DECISIONS.md, 2026-11-24 T-011: commit-relative scope is unstable; reviewers use `main...HEAD`).
