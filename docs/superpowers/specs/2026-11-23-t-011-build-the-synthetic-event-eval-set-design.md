# T-011: Build the synthetic event eval set and record the baseline

Request R-003. Plan: `docs/superpowers/plans/2026-11-23-t-011-build-the-synthetic-event-eval-set.md`.

## Product Owner request

Highlight theo sự kiện: gắn nhãn bàn thắng, cứu thua, thẻ đỏ, pha tranh cãi. Người dùng lọc "chỉ bàn thắng" hoặc "top 5 pha hay".

## Goal

Add `tests/fixtures/eval/build.py`. It writes 3-4 short synthetic matches with ffmpeg as `<match>/video.mp4`, which stays gitignored and is never committed, next to committed `labels.json`, each with known events. Cues per event: goal = a sustained roar (≥ 8 s) plus a digit change in a fixed top-left scoreboard box plus a short repeated (replay) section; save = a sharp roar of 2-3 s with no scoreboard change; red_card = a 3 kHz whistle, a quiet stoppage, then a red-dominant close-up for a few seconds; controversy = a whistle, a long stoppage (≥ 30 s) with low-frequency booing noise, and a replay. Add distractor crowd noise with no event so precision means something. Run the current pipeline, where everything is `other`, and record the baseline JSON in the README. Assumptions: the eval command becomes `python tests/fixtures/eval/build.py && sportscut eval tests/fixtures/eval --json`, and the build is idempotent (it skips matches that already exist). Each match is ≤ 3 minutes long at 160x90 so CI stays fast.

## Acceptance criteria

- AC1: `tests/fixtures/eval/build.py` exists, imports only numpy and the stdlib (no `sportscut` import), and exposes HERE, W=160, H=90, FPS=10, AUDIO_RATE=16000, SCOREBOARD=(2,2,30,14), MATCHES (keys exactly 'cards','controversy','goals_saves','mixed' with the events listed in the spec), SEEDS, DISTRACTORS=('swell','chant'), match_labels, footprints, score_at, play_clock, render_frame, audio_track and build_all.
- AC2: For every match, the committed `tests/fixtures/eval/<match>/labels.json` equals `json.dumps(build.match_labels(name), indent=1) + '\n'` byte for byte. Each label has exactly the keys start, end and type, its type is one of goal/save/red_card/controversy, and labels are sorted by start. Across the set there are exactly 5 goal, 5 save, 3 red_card and 3 controversy labels (16 total), plus 5 distractors in MATCHES that produce no label. No video file is tracked by git under tests/fixtures/eval/.
- AC3: Every match has duration 180.0 (<= 180). All footprints lie within [10, duration-10], and consecutive footprints in a match are at least 12 s apart.
- AC4 (scoreboard): Sampling render_frame every 0.1 s, the SCOREBOARD crop changes exactly once per goal, between t0+0.9 and t0+1.0, and is identical at all other consecutive samples. score_at returns the running (home, away) with the correct team incremented, starting from (0,0), and no frame outside the box changes because of the score.
- AC5 (red close-up): A pixel counts as red when R>=150, G<=60 and B<=60. Its share of the frame is >= 0.6 for every sample in each red_card window [t0+4, t0+8) and <= 0.05 for every 0.1 s sample outside those windows in all matches.
- AC6 (replay): For each goal, render_frame at t0+13+k equals render_frame at t0-3+k outside the SCOREBOARD box, for k in 0..4.9 step 0.1. For each controversy, t0+20+k equals t0-6+k for k in 0..5.9. At times that are outside frozen spans and replay windows, the frame at t differs from the frame at t-1.0 (the ball moves). Inside a frozen span and outside its replay window, consecutive frames are identical.
- AC7 (audio level cues, pure audio_track, 0.1 s RMS windows, murmur = 0.02): For each goal, the level stays >= murmur+12 dB for at least 8.0 s starting within 0.5 s of t0. For each save, the level is >= murmur+12 dB for between 2.0 and 3.0 s in total. Inside [t0+1.5, t0+11.5] of each red_card the level is <= murmur-6 dB. For each distractor, the peak 1 s RMS is between murmur+6 dB and murmur+16 dB, and the level takes >= 1.0 s to rise from murmur+3 dB to the peak (saves take <= 0.2 s).
- AC8 (audio spectral cues, pure audio_track): The 2800-3200 Hz band holds >= 0.8 of the energy in [t0+0.1, t0+0.9] of every red_card and controversy whistle, and <= 0.05 in every other whole second of every match that does not overlap a whistle. Below 220 Hz, the band holds >= 0.6 of the energy in every whole second inside [t0+4, t0+32] of each controversy, and <= 0.2 in every whole second outside the booing spans.

## Decisions

- T-011 (R-003): The synthetic event set lives in `tests/fixtures/eval/<match>/{video.mp4,labels.json}` and is generated by `tests/fixtures/eval/build.py` (numpy + stdlib only, no sportscut import). The eval command is `python tests/fixtures/eval/build.py && python -m sportscut eval tests/fixtures/eval --json`. video.mp4 is gitignored by the existing `*.mp4` rule; labels.json is committed and must equal the generator output.
- T-011 (R-003): The set is 4 matches ('cards', 'controversy', 'goals_saves', 'mixed'). Each lasts 180 s at 160x90 and 10 fps, encoded as mpeg4 -q:v 2 video with mono 16 kHz AAC 64k audio. Together they hold 5 goal, 5 save, 3 red_card and 3 controversy labels and 5 unlabelled distractors (swell, chant). The timelines in MATCHES are fixed: changing them is a spec change and requires re-recording the baseline.
- T-011 (R-003): Cue design. goal = a crowd roar of +20 dB for 10 s, a digit change at t0+1 in the fixed top-left scoreboard box (2,2,30,14), and a replay of [t0-3,t0+2) at [t0+13,t0+18). save = a sharp +20 dB roar of about 2.5 s with nothing else. red_card = a 3 kHz whistle for 1 s, quiet (-12 dB) with the ball frozen for 12 s, and a red-dominant close-up at [t0+4,t0+8). controversy = a whistle, a 36 s frozen stoppage with 30 s of 60-200 Hz booing, and a replay of [t0-6,t0) at [t0+20,t0+26). Crowd noise is 200-2000 Hz, so the 3 kHz and sub-220 Hz bands are clean signals.
- T-011 (R-003): Label spans cover the viewer moment, not the whole stoppage or replay: goal [t0-2,t0+10], save [t0-4,t0+4], red_card [t0-2,t0+8], controversy [t0-4,t0+6]. All are <= 12 s, so one default 12 s detector window can match them.
- T-011 (R-003): The scoreboard shows the live score during replays, so the score changes exactly once per goal. Replays reuse the base picture (pitch plus ball), and the ball position follows a play clock that stops during stoppages.
- T-011 (R-003): Generation is deterministic (per-match numpy seeds 1101+index) and idempotent. Labels are rewritten only when they differ. A video is encoded only if it is missing, its labels changed, or --force is given. Writes go to the dot-prefixed `.video.tmp.mp4` and then `os.replace`, so a crash never leaves a second visible video.
- T-011 (R-003): The baseline is recorded once in README.md under 'Baseline đo trong T-011' as the exact one-line eval output. Tests check only invariants of that recorded JSON (all four R-003 recalls 0.0, precision < 1) and never compare it with a live run, so later classifier tasks do not have to edit T-011 tests.
