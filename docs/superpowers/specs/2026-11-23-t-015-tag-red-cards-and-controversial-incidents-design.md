## Product Owner request

Highlight theo sự kiện: gắn nhãn bàn thắng, cứu thua, thẻ đỏ, pha tranh cãi. Người dùng lọc "chỉ bàn thắng" hoặc "top 5 pha hay".

## Goal

red_card = a whistle followed by a stoppage (low play-sound activity ≥ 20 s) and a red-dominant close-up: saturated red pixels in the frame centre on frames sampled only inside the candidate window, never across the whole match (see Decisions: 8 s, 15 s after the whistle). Controversy (VAR checks, disputed penalties, disallowed goals, protests) = a whistle plus a long stoppage (≥ 30 s) with sustained low-frequency crowd booing and/or a replay (frames repeating). A scoreboard change followed by a reverted change also counts as controversy (disallowed goal). Precedence when cues overlap: goal > red_card > controversy > save. Report per-event numbers before and after in the PR. Merge only if red_card and controversy recall go up and overall F1 and goal recall do not go down. Assumption: these are ffmpeg-only heuristics with lower confidence (`event_confidence`). Vision models (e.g. card or referee detection) are explicitly out of scope, to be done later as an optional `[vision]` extra if real-match numbers demand it.

## Decisions

- T-015 (R-003): Incident tagging lives in `sportscut/events/incidents.py`. Entry point: `tag_incidents(video, segments) -> list[Segment]`. Helpers: `red_share`, `booing_seconds`, `classify`, plus the I/O helper `sample_frames(video, start, duration)`. It reuses `audio_cues.find_whistles`, `stoppage_after` and `band_share` without changing audio_cues.py. `sample_frames` stays in incidents.py (not media.py) because media.py is frozen by the T-014 AC15 scope test. It reuses `media.find_tool`, `MediaError` and `_failure_detail`.
- T-015 (R-003): Classifier chain is find_highlights -> tag_goals -> tag_incidents -> tag_saves -> select_segments in `pipeline.run`. `evaluate_dir` scores `audio_cues.tag_saves(video, incidents.tag_incidents(video, scoreboard.tag_goals(video, detect.find_highlights(video))))` through module attributes. This updates the T-013/T-014 chain decisions.
- T-015 (R-003): Precedence goal > red_card > controversy > save comes from the chain order. tag_incidents reads only `other` segments for whistle cues and only `goal` segments for the reverted-board cue. red_card is checked before controversy, and tag_saves only tags what is still `other`.
- T-015 (R-003): red_card rule: a whistle starting inside the segment ([start, end)), stoppage_after(whistle end) >= 8.0 s, and at least 2 frames with red_share >= 0.5. Red pixel: R>=150, G<=60, B<=60 in the centre crop rows [h/4, 3h/4), cols [w/4, 3w/4). Frames are sampled at 2 fps, 160x90, only on [whistle end, whistle end + 15 s), and only for whistles that already passed the stoppage check. Confidence 0.5. Reason suffix: '; whistle at {ws:.0f}s, stoppage {stop:.0f}s, red close-up'.
- T-015 (R-003): The red_card stoppage threshold is 8 s instead of the 20 s in the task text. The frozen synthetic set models a 12 s freeze (measured 9-13 s in T-014 AC10), so 20 s would give red_card recall 0. The red close-up is the discriminating cue. Revisit with the PO's labelled data/eval/.
- T-015 (R-003): controversy rule (audio): a whistle starting inside the segment, a stoppage >= 30.0 s, and booing >= 10.0 s. Booing = 0.1 s windows in [whistle end, whistle end + stoppage) whose 20-220 Hz band share is >= 0.5. Confidence 0.4. Reason suffix: '; whistle at {ws:.0f}s, stoppage {stop:.0f}s, booing {boo:.0f}s'. Replay detection is deferred.
- T-015 (R-003): Reverted scoreboard: `scoreboard.find_reverts(frames, box, changes)` pairs adjacent changes (c1, c2) with c2 - c1 <= 180 s. It compares the board at int(c1)-1 with the board at min(int(c2)+3, n-1): fewer than 3% of pixels differing by >= 40 means a revert. `scoreboard.board_reverts(video)` returns [] without a visible board. A goal segment whose reason contains tag_goals' marker 'scoreboard change at {c:.0f}s' for c1 or c2 becomes controversy with confidence 0.5 and the suffix '; scoreboard change at {c1:.0f}s reverted at {c2:.0f}s'. The tag_goals reason format (T-013) is therefore a contract.
  Updated by T-015 (dev): the revert test uses its own `REVERT_FRAC = 0.01` (fewer than 1% of board pixels differ), not `CHANGE_FRAC` (3%). On the built 'mixed' match (0-0 -> 1-0 -> 2-0) the '2' glyph differs from '0' in only 2.58% of board pixels, so the 3% rule called it a revert and relabelled both goals as controversy (goal recall 0.6). Unchanged board states measure 0.0 on the built set. See the plan's Deviations section.
- T-015 (R-003): tag_incidents decodes only what it needs. The scoreboard top band is decoded only if a goal segment exists, and audio only if an `other` segment exists. Frames are decoded per qualifying whistle window and never across the whole match. Segment geometry, score, order and count never change.
