# T-047: Add `sportscut meta OUT_DIR` writing title, caption and hashtags into highlights.json, captions.txt and reel.json

Request R-005. Plan: `docs/superpowers/plans/2026-11-27-t-047-add-sportscut-meta-out-dir-writing.md`.

## Product Owner request

Bình luận AI: tạo tiêu đề, caption, hashtag, thậm chí lồng tiếng bình luận tiếng Việt.

## Goal

Request R-005. Re-lands the first slice of the dropped T-024 (read its spec plus the T-023, T-046/T-025 and T-028 specs first). New module sportscut/commentary/publish.py has `write_meta(out_dir, match=None, backend='template')`. It reads OUT_DIR/highlights.json and builds ClipFacts per entry with facts_from_entry(entry, match). It generates metadata with generate_meta (backend 'template') or generate_metas_llm in one request (backend 'llm'; template fallback per clip, as in T-025). It adds `title`, `caption` and `hashtags` as the last keys of each entry and rewrites highlights.json (UTF-8, ensure_ascii=False). It writes OUT_DIR/captions.txt, one block per clip ready to paste: file name, title, caption, then the hashtags on one line, blocks separated by a blank line. It writes OUT_DIR/reel.json with one reel-level {title, caption, hashtags} for the whole set; its facts are the match info plus the event counts, and it must pass eval_meta.format_problems. CLI: `sportscut meta OUT_DIR [--home H] [--away A] [--competition C] [--kickoff SECONDS] [--match-info match.json] [--meta-backend template|llm]`. Explicit flags override match.json keys. The minute is computed only when a kickoff is given, as the T-023 assumption says. A missing or invalid highlights.json exits 1 with a clear stderr message. Without team info the text stays generic and names no teams. Files: sportscut/commentary/publish.py (new), sportscut/cli.py, tests/test_commentary_publish.py (new), README.md (insert-only, per the T-042 append-only tests), docs/superpowers spec and INDEX line. Do not touch facts.py, meta.py, llm.py, pipeline.py, api.py. Tests (TDD, synthetic manifest in a tmp dir, no ffmpeg needed): the fields are present and pass format_problems; the text contains no team or number absent from the facts; captions.txt has one block per clip; reel.json is valid; the llm backend with a fake client writes LLM text, and a hallucinating client falls back to the template. Verify: `python -m pytest -q` 0 failed; `python -m sportscut eval-meta tests/fixtures/eval_meta --json` score unchanged at 1.0; `sportscut eval` F1 unchanged; diff < 400 lines outside docs/superpowers.

## Decisions

- T-047 (R-005): `sportscut/commentary/publish.py` owns publishing. It provides `write_meta(out_dir, match=None, backend='template', client=None) -> list[dict]` and `reel_meta(facts_list) -> ClipMeta`. `client` exists only so tests can inject a fake Anthropic client, and it is passed straight to `llm.generate_metas_llm`.
- T-047 (R-005): The template backend calls `generate_meta(facts_i, clip=i)` with the 0-based manifest index, so clips vary (T-050 hash). The llm backend makes one `generate_metas_llm` call per match, and its per-clip fallback is llm.py's unchanged `generate_meta(facts)` (no clip index).
- T-047 (R-005): Entries get `title`, `caption` and `hashtags` (list) as their last three keys. Any existing values for these keys are replaced, and all other keys keep their order and values. highlights.json, captions.txt and reel.json are written UTF-8 with ensure_ascii=False and indent=2 (JSON files), ending with '\n'. They are written only after every input has been validated and all text generated, so an error leaves every file unchanged.
- T-047 (R-005): An entry whose event is missing or outside EVENT_TYPES is treated as 'other' (T-028 rule). An empty highlights.json list is an error.
- T-047 (R-005): captions.txt holds one block per clip in manifest order: file, title, caption and the space-joined hashtags on four lines. Blocks are joined by one blank line, and the file ends with a single newline. The reel is only in reel.json.
- T-047 (R-005): The reel text is always template. The title is 'Tổng hợp highlight: {teams}', falling back to 'Tổng hợp highlight trận đấu' (the T-028 REEL_DEFAULT title). The caption is 'Tổng hợp {n} khoảnh khắc đáng chú ý' + T-023 match text + optional ' tại C' + ': ' + lowercased event counts in EVENT_TYPES order + '.' + optional ' Tỉ số: S.' + ' Cùng xem lại nhé!'. If it is over 300 characters, the counts part is dropped. The hashtags are #BongDa #Highlight #TongHop, then the home/away/competition tags, then the counted event tags, deduplicated case-insensitively and capped at 8.
- T-047 (R-005): The match info for `sportscut meta` comes from `--match-info` (a JSON object using the facts.MATCH_KEYS keys home, away, competition, score, kickoff), and the explicit flags --home, --away, --competition and --kickoff override its keys. The minute is computed only when a kickoff is given (T-023).
- T-047 (R-005): `sportscut meta` exit codes: 0 on success, printing the three written paths one per line. 1 for any ValueError or OSError (highlights.json, match.json, bad match values), with 'sportscut meta: error: <msg>' on stderr and an empty stdout. 2 for argparse usage errors.
- T-047 (R-005): cli.py and README.md changes are insert-only. The README section goes before '## Theo dõi cầu thủ: đo độ chính xác (eval-player)' and contains no '```json' (T-027 AC16), and the eval-crop section stays last (T-042).
- T-047 (R-005): Size budget is < 400 changed lines outside docs/superpowers (publish.py ≈ 90, cli.py ≈ 35, README ≈ 20, Developer tests ≤ 130, Tester acceptance ≤ 120). Scope and size are checked by commands and in review, not by pytest git-diff tests (T-028 rule). The eval-meta score stays 1.0 and eval F1 is unchanged.
